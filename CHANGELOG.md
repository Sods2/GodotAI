# Changelog

## [1.1.3] - 2026-10-15

- Cancel mid-stream removes the partial assistant bubble and the unanswered user message
- Clear aborts an in-flight stream so late tokens cannot recreate chat bubbles
- Chat prose is selectable (drag-select, right-click Copy); each message has a Copy button
- Slightly higher scroll deadzone so short mouse drags prefer text selection over scrolling

## [1.1.2] - 2026-10-15

- Soft default AI Chat dock width (~22% of editor width, floor 200px)
- User chat bubbles wrap instead of clipping mid-word
- Markdown fences tolerate stray backticks before code fences
- Narrow-dock layout and toolbar stacking fixes

## [1.1.1]

- Itch-parity chat build (see prior releases)

## [1.1.0]

- Published itch baseline
